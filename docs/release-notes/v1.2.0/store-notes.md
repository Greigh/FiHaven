## App Store — What's New in This Version

```
NEW CAPABILITIES

A Loans tab. A rewards optimizer that answers "which card should I use for this
purchase?". Transaction logging, net worth, savings goals and a subscription
finder.

Optional bank linking via Plaid for Pro — it adds transactions alongside your
own and never overwrites what you entered manually.

Autopay auto-mark for Pro, skip-this-month, and income adjustments for bonuses
or unpaid time off.

FREE VS PRO

Pro unlocks the payoff planner, calendar, history, rewards optimizer,
subscriptions, category budgets, bank sync and autopay marking.

SECURITY

Rate limiting, a stronger Android app lock, and code-scanning fixes.
```
