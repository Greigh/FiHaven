## App Store — What's New in This Version

```
SECURITY

Household invite emails are validated more safely before sending — the address
check is now shared and capped at 254 characters, closing a code-scanning alert
about a slow regular expression.

The information security policy now documents when automated code scanning runs:
on pushes to main, weekly, and on demand.

ANDROID

Intro screen icons are mirrored for right-to-left languages.
```
