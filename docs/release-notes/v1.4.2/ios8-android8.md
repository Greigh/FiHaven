## App Store — What's New in This Version

```
PRO & FAMILY

The intro and onboarding now explain what Pro includes — payoff planner, family
sharing, calendar, rewards, category budgets — instead of just asking you to buy
it.

The paywall and Family settings spell out that invitees can join a household for
free. Pro is for creating and managing a family, not for being in one.

LEGAL

The repo license is now source available rather than AGPL: the code stays public
for transparency, but running a competing hosted copy requires permission. Terms
of Use clarify how that license relates to using fihaven.app.

RELIABILITY

iOS builds on CI use the full Xcode toolchain again, fixing broken automated
builds.
```
